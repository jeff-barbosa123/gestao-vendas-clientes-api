Descrição da Funcionalidade Descrição da Funcionalidade Como um empreendedor (confeiteiro, boleira ou cozinheiro), quero simular o preço ideal de venda a partir da ficha técnica cadastrada, para avaliar cenários de precificação, garantir lucro real e ajustar margens, sem persistir dados ou alterar receitas existentes. Esta funcionalidade consome o CMV calculado na US005, aplicando margens de lucro para fins exclusivamente consultivos, sendo crítica para decisões estratégicas de venda, promoções e posicionamento de preço. 2. Escopo 2.1 Em Escopo Simulação de preço via ID de receita Simulação rápida via ficha técnica enviada no payload Aplicação de margem de lucro Cálculo de: custo total custo por unidade preço mínimo preço ideal Arredondamento financeiro Segurança (JWT, ownership , IDOR) Performance e concorrência Não persistência de dados Observabilidade (logs) 2.2 Fora de Escopo Persistência de simulações Interface Web Histórico de simulações Relatórios consolidados Integração automática com vendas Cálculo de CMV (responsabilidade da US005) 3. Regras de Negócio A simulação deve utilizar: ingredientes custos overheads mão de obra rendimento Margem de lucro é obrigatória Margem pode variar entre simulações Receita original não pode ser alterada Receita inexistente deve retornar erro Simulação rápida não gera registros Valores financeiros devem: ser ≥ 0 (exceto margem negativa, se permitida) ser retornados com 2 casas decimais Acesso restrito ao dono da receita ( ownership ) 4. Qualidade Técnica Idempotência : mesma entrada → mesmo resultado Determinismo: cálculos previsíveis Consistência financeira Precisão de arredondamento Isolamento: sem efeitos colaterais no banco 5. Segurança JWT obrigatório Bloqueio de: token inválido token ausente token expirado IDOR enumeração de IDs mass assignment Validação rigorosa de payload 6. Performance Tempo de resposta &lt; 500ms Suporte a simulações concorrentes Estabilidade sob carga Nenhuma degradação progressiva ( soak ) Requisitos Testados (API) User Story : US006 – SGVC: Simulação de Preço Ideal (Pré-Venda) ID Tipo Requisito Descrição REQ-SIM-001 API-SIM-001 a 005 Simulação de preço via ID da receita Validar a simulação de preço ideal a partir de uma ficha técnica existente, garantindo o cálculo correto do custo total, custo por unidade, preço mínimo e preço ideal, retornando 200 OK quando os dados forem válidos. REQ-SIM-00 7 API-SIM-022 a 024 Não persistência da simulação Garantir que nenhuma simulação de preço gere persistência de dados, criação de registros ou alteração da ficha técnica original.
